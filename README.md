# Local–Global Joint Modeling for Point Cloud Super-Resolution Guided by Multi-Scale Spatial Priors
Abstract: *Range-image-based point cloud super-resolution projects a low-resolution LiDAR point cloud onto a regular two-dimensional representation and thereby provides an effective route to reconstructing sparse point clouds in outdoor scenes. Existing methods, however, still exhibit three limitations. First, range images exhibit pronounced density variations, with sparse regions in the upper part and dense regions in the lower part. Cross-scale fusion mechanisms that do not account for these sparse–dense variations can propagate zeros and noise from distant sparse regions into the decoder. Second, a single convolutional or sequence-modeling architecture has difficulty preserving local high-frequency geometry while capturing global long-range dependencies, often producing over smoothed reconstructions. Third, smooth depth transitions near foreground–background boundaries can become spike artifacts after back-projection into three-dimensional space. To address these issues, we propose a multi-scale-spatial-prior-guided local–global framework comprising a SpatialGateFuse module, a local–global selective state-space (LG-SSM) block, and two-dimensional median-residual denoising. Experiments on KITTI-360 and nuScenes demonstrate effective reconstruction, achieving intersection-over-union scores of 0.4703 and 0.3593, respectively. These results validate the feasibility of the proposed framework for range-image super-resolution.*
